# 历史生成文件按需恢复

目标：同一会话隔天继续修改 PPTX 等历史产物时，从现有持久化备份恢复二进制原件到新沙箱。

采用已有 session_files 清单和 SESSION_FILES_PERSIST_DIR，增加 ListHistoryFiles / RestoreHistoryFile 工具。每次工具调用校验会话归属；精确相对路径选择文件，同名歧义要求明确路径。恢复不覆盖当前文件，失败明确返回错误。

比较过每轮全量恢复、共享挂载、按需恢复：用户已选择按需恢复，避免无关请求搬运全部文件，也不要求修改现有存储部署。跨副本使用同一共享备份目录；不能从其他 Pod 私有磁盘猜测取回文件。

恢复后的签名记录在请求级 RoundState 中。未改动的恢复文件不重新登记为本轮生成，修改后的文件继续走已有检测和持久化链路。Bash 使用实际会话工作目录；新版本沿用现有另存新文件名约定。

范围：恢复已成功备份的生成文件；保持上传解析文本自愈。既有同路径覆盖产生的旧版本、未备份中间文件无法凭空重建。权限、路径穿越、符号链接逃逸、二进制完整性、并发不覆盖、恢复后文件归属必须回归。
