## 1. 适用场景

### 1.1 音频素材

- 会议录音（班子会、专题会、调度会、全体会）
- 领导即兴讲话、现场发言
- 访谈录音、调研座谈录音
- 电话会议、视频会议录音

### 1.2 未整理文本素材

- 语音转文字速记稿（口语化严重、无标点、无分段）
- 会议原始记录（流水账式）
- 零散笔记、工作日志、随手记
- 讲话提纲、PPT 备注、汇报要点

### 1.3 典型需求对照

| 素材 | 常见产出 |
|------|---------|
| 专题会议录音 | 会议纪要、会议简报 |
| 领导现场讲话 | 讲话稿（整理成文）、讲话要点摘编 |
| 工作汇报录音 | 正式工作汇报材料 |
| 调研座谈录音 | 调研报告、情况反映 |
| 零散工作笔记 | 工作总结、经验材料 |

## 2. 音频转写要点

### 2.1 转写工具

- 优先使用可用的语音转文字能力（如 Whisper 系列、飞书妙记、通义听悟、讯飞听见等）。
- 本地音频可用 Whisper 命令行转写；在线工具注意上传合规性，涉密内容不得上传外部平台。
- 转写参数建议：识别语言设为中文；如支持，开启说话人分离（区分"张书记""李局长"等）。

### 2.2 转写后的初步清洗

转写稿普遍存在以下问题，需先清洗：

| 问题 | 示例 | 处理 |
|------|------|------|
| 语气词 | "嗯""啊""那个""就是说" | 删除 |
| 重复啰嗦 | 同一句话反复说、口误后重说 | 保留一次，取最完整表述 |
| 断句错误 | 无标点、长句粘连 | 按语义重新断句 |
| 同音错字 | "部署"写成"不熟"、"调研"写成"掉烟" | 结合上下文校正 |
| 专有名词错误 | 人名、地名、单位名、术语 | 重点核对校正 |

### 2.3 转写稿标注

- 多人发言：标注说话人（如"张书记：""李局长："）。
- 听不清/不确定处：标注"[听不清]""[待确认]"，不要臆造。
- 重要数据、时间、人名：重点核对，整理后列入"待确认清单"。

## 3. 内容解构方法

### 3.1 三步解构法

1. **通读定主线**：通读全文，判断素材围绕什么主题、解决什么问题。
2. **聚类分板块**：把碎片化内容按主题聚类，形成若干板块。
3. **提炼三要素**：每个板块提炼出"核心观点 + 关键数据 + 具体举措"。

### 3.2 信息分层

| 层级 | 内容 | 处理方式 |
|------|------|---------|
| 观点层 | 结论、判断、要求 | 直接转化为公文观点句 |
| 事实层 | 数据、案例、进展 | 核实后作为论据 |
| 举措层 | 部署、安排、下一步 | 转化为"要/将/需"句式 |
| 寒暄层 | 客套话、即兴发挥 | 视文稿类型取舍 |

### 3.3 待确认清单

整理过程中遇到以下情况，单独列出"待确认清单"，成稿后请用户核对：

- 具体数字（"大概三四个亿"→ 需确认准确数）
- 人名、职务
- 单位名称、项目名称
- 时间节点
- 引用的政策文件名称

## 4. 去口语化与规范化

### 4.1 去口语化对照表

| 口语表达 | 公文表达 |
|---------|---------|
| 我们觉得 / 我寻思 | 会议认为 / 我们认为 |
| 干得不错 / 干得挺好 | 成效明显 / 进展顺利 |
| 搞了好几个项目 | 实施了一批重点项目 |
| 接下来要 / 后面要 | 下一步将 / 下阶段要 |
| 挺重要的 / 特别重要 | 意义重大 / 至关重要 |
| 那个啥 / 就是说 / 然后 | （删除） |
| 老百姓 / 群众 | 人民群众 / 基层群众 |
| 花钱 / 投钱 | 投入资金 / 加大投入 |
| 出问题了 / 出事了 | 发生问题 / 出现偏差 |
| 抓紧弄 / 赶紧办 | 加快推进 / 抓紧落实 |
| 差不多 / 大概 | 基本 / 总体 |
| 一大堆 / 好多 | 一批 / 一系列 |

### 4.2 规范化要点

- **句式**：多用"要……""必须……""坚持……""着力……"等公文句式。
- **动词**：用"落实、推进、强化、深化、健全、完善"等规范动词。
- **数字**：模糊数字核实为准确数字；无法核实的用"约""左右"。
- **称谓**：统一规范称谓（如"市委、市政府"）。
- **层次**：按"一、（一）1.（1）"规范层次序号。

### 4.3 保留与舍弃

- **保留**：讲话人的核心观点、金句、独特比喻、惯用表达（体现风格）。
- **舍弃**：重复啰嗦、与主题无关的寒暄、内部玩笑、敏感不当表述。
- **改写**：口语化但信息量大的长句，拆分为规范短句。

## 5. 不同类型公文的整理要点

### 5.1 会议纪要

- 结构：会议概况（时间、地点、主持、出席）→ 议定事项 → 会议要求。
- 只记"议定事项"，不记讨论过程。
- 每条事项用"会议指出/会议强调/会议明确/会议要求"引出。
- 口语讨论转化为"会议认为"。

### 5.2 领导讲话稿

- 结构：开场（肯定成绩/点明主题）→ 主体（形势分析、重点部署）→ 结尾（要求、号召）。
- 保留领导个人风格和惯用表达。
- 口语化的部署转化为"要……""必须……"句式。
- 补充必要的政策依据（上情）提升高度。

### 5.3 工作汇报

- 结构：基本情况 → 主要做法 → 存在问题 → 下步打算。
- 从素材中提取做法、成效、问题、打算四类信息。
- 数据尽量完整呈现。

### 5.4 调研报告

- 结构：调研背景 → 基本情况 → 主要问题 → 对策建议。
- 访谈录音中的原话可作"群众声音"引用。
- 建议部分要具体可操作。

### 5.5 通知/通报

- 结构：缘由 → 事项 → 要求。
- 从会议决定中提炼事项。
- 语言高度凝练。

## 6. 常见问题与处理

| 问题 | 处理 |
|------|------|
| 素材信息不足 | 主动追问用户补充背景、数据、要求 |
| 内容相互矛盾 | 列出矛盾点请用户确认 |
| 涉及敏感表述 | 删除或委婉化处理 |
| 转写质量差 | 结合上下文推断，标注待确认 |
| 素材过长 | 先做要点摘要，再按需展开 |
| 用户只要"整理"不要"改写" | 忠实原意，仅做去口语化和结构化 |

## 7. 完整示例

### 7.1 原始转写稿（节选）

> 嗯，那个今天这个会，主要是研究一下咱们下半年的这个重点工作。啊，上半年整体来看，各项工作推进的还可以，但是也存在一些问题。那个，比如说重点项目这块，进度有点慢，好几个项目都卡在手续上。然后呢，安全生产这块，我们也不能放松，最近其他地方出了几起事故，教训很深刻。下一步，我觉得要重点抓三件事：第一，项目推进要提速，该并联审批的并联审批；第二，安全生产要大排查，把隐患消除在萌芽状态；第三，营商环境还要再优化，让企业少跑腿。大概就是这样，大家有什么意见再补充。

### 7.2 解构要点

- 主题：下半年重点工作部署
- 上半年：整体推进尚可，存在问题
- 问题：重点项目进度慢，卡在手续环节
- 要求：安全生产不能放松（外部事故警示）
- 部署：① 项目推进提速（并联审批）② 安全生产大排查（隐患消除在萌芽）③ 优化营商环境（让企业少跑腿）

### 7.3 整理成文（会议纪要节选）

> 会议指出，上半年各项工作总体推进有序，但重点项目推进存在进度滞后、手续办理不畅等问题，必须高度重视、加快解决。
>
> 会议强调，安全生产须臾不可放松。近期外地连续发生多起安全事故，教训极为深刻，必须举一反三、警钟长鸣，把隐患消除在萌芽状态。
>
> 会议明确，下一步要重点抓好三方面工作：一是加快项目推进，对符合条件的项目实行并联审批，切实压缩办理时限；二是开展安全生产大排查大整治，全面消除风险隐患；三是持续优化营商环境，精简办事流程，让企业少跑腿、好办事。
