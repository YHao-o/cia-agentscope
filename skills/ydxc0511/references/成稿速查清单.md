## 一、成稿前 10 条

- [ ] 领任务的四要素都确认过：背景、受众、类型、意图
- [ ] 提纲细化到三级标题，板块与标题一一对应
- [ ] 三集齐备：上情（政策文件、会议精神）、实情（本单位进展与短板）、真情（接地气的表达）
- [ ] 标题贴内容，用的是七种方式之一，不是硬凑对仗
- [ ] 篇幅按 250–300 字/分钟 反推过（讲话稿）
- [ ] 结构符合文种框架：讲话三段式、研讨"主题—意义—做法"、总结"引入—做法—展望"、致辞"欢迎—背景—期待"、法定公文按对应文种规范
- [ ] 润色五项过了一遍：标题亮眼、逻辑递进、语言精炼、有接地气表达、有金句
- [ ] 三审走完：总体浏览、逐字校对、诵读校对
- [ ] 模糊处标了【待确认】，没有靠猜
- [ ] 没有"高度重视"式空口号，没有"总之""综上所述"类套路词

## 二、新手七大误区与改法

| 误区 | 改法 |
|------|------|
| 标题堆砌对仗但不贴内容 | 先定内容要点，再回填标题关键词 |
| 通篇"高度重视"没有具体动作 | 每处表态补一件具体事：谁、做什么、什么时候 |
| 滥用"总之""综上所述"等 AI 腔 | 直接删，用一句实话接住 |
| 硬造无内涵的排比假金句 | 删掉；金句要能概括真实矛盾 |
| 素材一一陈列没有主线 | 先定一条主线，素材按主线取舍 |
| 讲话稿不按语速反推篇幅 | 按 250–300 字/分钟 折算时长 |
| 模糊处靠猜、不标待确认 | 标【待确认：××】，定稿前回填 |

## 三、金句与语言

- 金句贵在"一稿一两句"，堆多了反而落入套路（FAQ Q4）。
- 位置在标题与关键段落，服务于"令人眼前一亮"的阅读效果。
- 穿插俗语、歇后语等接地气表达，增强温度。
- 三类不能写：硬造的无内涵排比、换任何主题都能用的万能句、只有音韵没有实义的比喻。

## 四、篇幅基准

| 体裁 | 篇幅 |
|------|------|
| 领导讲话稿 | 按 250–300 字/分钟 反推 |
| 学习心得体会 | 800–1200 字 |
| 思想汇报 | 1200–1800 字 |
| 组织生活会发言 | 1500–2000 字 |
| 研讨发言稿 | 600–1000 字 |
| 散文式征文 | 1000–1500 字 |

## 五、FAQ

**Q1：只给个题目，素材以后补，能先写吗？** 可以先出"通用骨架稿"，但所有需要事实支撑的段落用【待补充：××】标注，定稿前必须回替换。

**Q2：能不能就把这篇文章改一改给我用？** 不能整段沿用（有抄袭和穿帮风险）。正确做法是执行"智能搜索参考工作流"的五层借鉴法，只迁移结构、标题与论证方法。

**Q3：范文里引用的会议精神能照着写吗？** 不行。范文反映的是当时的写作背景，引用前必须核对官方原文，拿不准先问用户。

**Q4：一篇材料能多用金句吗？** 金句贵在"一稿一两句"，堆多了反而落入套路。

**Q5：命令、议案这些很少用的法定公文，能写吗？** 能，但这类文种发文层级高（命令、公报多为中央层），实际动笔前先向用户确认发文机关层级与文种是否选对了——很多单位该用"通知/通报"的场合容易混用。

> 其他边界情况（需求超范围、引用文件未提供、数据模糊、素材互相矛盾）按主文件"边界处理与主动问询"一节的表格处置。
