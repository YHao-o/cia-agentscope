# 小型会议发言通用话语体系库

一般工作人员在小型会议上个人发言类文稿（学习心得、思想汇报、研讨发言、表态发言、对照检查、征文）的通用话语体系。适用于任何党政机关、企事业单位，**不含任何特定单位或行业的专属话语**。

> 关键提醒：本库只提供"通用底座"。用户所在单位的专有表述（单位口号、工作思路简称、行业精神谱系、年度主题等）必须**向用户索取后再使用**，不得凭空编造。

> 素材策略：**以搜索为主、内置为辅**——动笔前先按"一、素材搜索"检索优质素材；内置典故、句式作为种子保底，搜索无果或核对规范时使用。

---

## 一、素材搜索（写作前优先执行）

撰写个人发言类文稿前，先按本节检索三类素材；联网可用时**默认执行**（用户明确要求跳过或确无检索条件的，直接用内置种子库）。

### 搜什么：三类素材

| 类型 | 找什么 | 用于哪 |
|------|--------|--------|
| **上情素材** | 主题相关的权威论述、会议精神、政策表述 | "认识/感悟"段落，保证提法准确、有高度 |
| **语言素材** | 贴合主题的典故、诗词、金句 | 开篇、扣题、结尾升华 |
| **行文素材** | 同类主题的优质发言、心得 | 学句式与展开方式，不搬内容 |

### 去哪搜：渠道优先级

1. **官方原文**（求是网、新华社、人民网、中国政府网、学习强国）——政策表述与权威论述的准确性来源；
2. **党媒与权威评论**（人民日报评论、浙江宣传等）——金句与表达的打磨样板；
3. **微信公众号文章**（检索限定 `site:mp.weixin.qq.com`）——同类主题的发言样本。

> 分工提醒：整篇范文级检索（找范文、借鉴谋篇布局）走 `公众号范文检索.md`；本文件只管词句与表述素材。

### 怎么搜：检索式模板

先提取**主题词**（可加行业或岗位限定词），再套用：

| 找什么 | 检索式 |
|--------|--------|
| 上情素材 | `{主题} 重要论述`、`{会议或文件全称} 精神 要点` |
| 金句典故 | `{主题} 金句`、`{主题} 典故 启示`、`{主题} 经典引用` |
| 行文素材 | `{主题} 心得体会 site:mp.weixin.qq.com`、`{主题} 研讨发言 体会` |

多轮策略：一轮不理想就换同义主题词（如"担当"→"责任意识"→"干事创业"）；近 3 年文章优先；政策口径取最新。

### 怎么筛：优质素材标准

1. **贴合主题**——能直接服务本篇立意或表达（必要条件）；
2. **可迁移**——学的是句式与用法，不搬运事实与内容（必要条件）；
3. **来源权威**——官方、党媒、行业权威优先；
4. **时效新鲜**——近 3 年优先，政策表述以最新口径为准。

来源存疑、口径过时、与主题牵强的一律不用；宁少而精，不求多而杂。

### 使用红线

1. **只学句式与用法**，严禁整句、整段照抄；
2. 政策表述、会议精神名称**回验官方原文**，搜索只作线索、不作依据；
3. 典故、引用每篇不超过 3 处；
4. 搜不到合适素材时用内置种子库保底，**宁缺毋滥、绝不编造**。

## 二、经典典故与引用（内置种子库）

### 经典引用（每篇建议使用不超过 3 处）

> 写作时优先搜索同主题更贴切的引用；搜索无果时使用以下保底内容。

| 典故 | 适用语境 |
|------|----------|
| 苟日新，日日新，又日新 | 强调持续学习、自我革新 |
| 九层之台，起于累土 | 强调脚踏实地、积累 |
| 为学之实，固在践履 | 强调知行合一 |
| 路虽远，行则将至；事虽难，做则必成 | 强调实干坚持 |
| 勿以恶小而为之，勿以善小而不为 | 廉洁自律语境 |
| 学如逆水行舟，不进则退 | 强调学习紧迫感 |
| 纸上得来终觉浅，绝知此事要躬行 | 强调实践 |
| 立志而圣则圣矣，立志而贤则贤矣 | 青年立志语境 |
| 大江来从万山中，山势尽与江流东 | 结尾升华、坚定前行 |
| 今日长缨在手，何时缚住苍龙 | 结尾升华、决心表态 |

### 固定政治表述（必须准确，不可篡改）

- 增强"四个意识"、坚定"四个自信"、做到"两个维护"
- 深刻领悟"两个确立"的决定性意义
- 习近平新时代中国特色社会主义思想
- 党的二十大和二十届历次全会精神（具体哪一次以用户提供的会议素材为准）
- 中央八项规定及其实施细则
- 《习近平关于加强党的作风建设论述摘编》
- 一体推进"三不腐"
- 纠"四风"、树新风
- 中国式现代化
- 高质量发展、新发展格局
- 以人民为中心的发展思想

> 引用上级讲话、文件、会议精神时，名称必须准确到全称、层级和时次；**具体表述以官方原文为准，引用前先搜索回验或向用户索取素材，禁止虚构**。

## 三、岗位锚点的通用写法

个人发言类文稿必须有"岗位落脚"——把学习感悟落到本人本职工作的具体行动上。不同岗位的通用锚点方向：

### 综合/行政类岗位
- 在办文办会办事的规范化、精细化上下功夫
- 提升统筹协调、服务保障能力
- 把每一项日常事务都当作提升能力的练兵场

### 业务/经办类岗位
- 吃透政策、规范流程，把经办事项办准确、办精细
- 主动向前一步，从"办完"走向"办好"
- 紧盯经办环节的风险点，守住底线、不越红线

### 服务/窗口类岗位
- 以"群众满意不满意"为标尺改进服务
- 换位思考，把服务对象的小事当作自己的大事

### 廉洁自律（各岗位通用）
- 始终绷紧廉洁自律这根弦，自觉抵制各种诱惑
- 管住小事小节，做到心有所畏、言有所戒、行有所止
- 主动接受组织和同志们的监督

### 通用句
- 以"时时放心不下"的责任感对待每一项工作
- 做本职工作的亲历者、实践者、推动者
- 从小事做起、从身边做起、从现在做起
- 在实际工作中体现党员的先锋模范作用

## 四、常用句式模板

> 以下句式用于保底与防"AI 腔"；写作时优先化用搜索到的更贴题表达。

### 开篇引入
- "XX报告/讲话/精神高屋建瓴、内涵丰富，既全面总结了XX，又科学谋划了XX，为我们指明了方向、明确了路径"
- "通过这次学习，我深受教育、倍感鼓舞，进一步明确了作为XX工作者（或：一名普通党员/青年职工）的责任与方向"
- "这次培训/研讨对我来说既是一次思想的淬炼，也是一场精神洗礼"

### 分论点展开
- "一是XX；二是XX；三是XX"（并列式）
- "深学XX、细悟XX、笃行XX"（三段推进式）
- "以学促思XX、以悟促改XX、以行促效XX"（三段推进式）
- "在XX上更进一步、在XX上更深一层、在XX上更严一分"（排比递进式）

### 岗位落脚
- "作为一名XX（岗位）人员，我必须……"
- "结合工作实际，我将从以下几个方面做起……"
- "立足本职岗位，把学习成效转化为……的实际行动"

### 结尾升华
- "蓝图已绘就，奋进正当时"
- "大江来从万山中，山势尽与江流东。我将以此次学习为新的起点……"
- "路虽远，行则将至；事虽难，做则必成"
- "以实际行动为单位高质量发展贡献自己的绵薄之力，在平凡岗位上书写不平凡的坚守"

## 五、禁用表述

- "总之""综上所述""值得一提的是""需要指出的是"（AI腔）
- 凭空编造的会议名称、领导讲话、文件名称
- 通用化、去岗位化的空话（如只说"努力奋斗、积极进取"而不落到本人具体行动）
- 同一精神表述或典故在一篇里反复引用
- "深刻认识到"连续使用超过 3 次
- 任何特定单位、特定行业的专属名词（用户未提供素材时）
