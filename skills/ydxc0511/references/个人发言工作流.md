# 一般工作人员小型会议发言工作流

> 个人发言类需求（心得、汇报、对照检查、研讨、征文）读本文件；按体裁只读对应模板章节。

## 一般工作人员小型会议发言工作流

当用户的需求是**一般工作人员（非领导）在支部学习、党小组会、处务会、科室例会、青年理论学习小组、培训交流等小型会议上的个人发言类文稿**时，走本工作流。与领导讲话稿的区别：视角是"我"的一线工作者，口吻谦逊务实，重在"学思践悟"与岗位落脚，不需部署工作、不需宏大叙事。

### 体裁识别与路由

用户通常只提供主题，需要从主题判断体裁；不确定时主动询问确认。

| 用户说的关键词 | 体裁 | 模板位置 |
|-------------|------|---------|
| 学习心得、学习体会、学习XX精神、学习贯彻 | 学习心得体会 | `references/个人发言体裁模板.md` 第 1 节 |
| 思想汇报、培训心得、培训汇报 | 思想汇报 | 同上，第 2 节 |
| 组织生活会、对照检查、查摆问题 | 组织生活会发言 | 同上，第 3 节 |
| 发言稿、研讨发言、表态发言 | 研讨发言稿 | 同上，第 4 节 |
| 征文、散文、演讲 | 散文式征文 | 同上，第 5 节 |

### 写作步骤

1. **识别体裁**：按上表路由到对应模板。
2. **确认关键参数**：主动确认三件事——①发言的场合与主题 ②学习/参考的具体文件、会议、讲话名称及要点（否则无法准确引用，宁可询问也不编造） ③发言人的岗位情况（用于岗位落脚）。
3. **加载话语体系**：读取 `references/个人发言话语体系.md`，统一用词规范。
4. **按体裁模板生成**：结构套用模板，写入 `output/` 目录交付。
5. **质检**：对照下方"质量自检清单"逐项确认。

### 核心原则

1. **身份锚定**：以普通工作人员第一人称视角写作，所有感悟最终必须落到**本职工作的一条具体行动**上（如经办事项的规范化、效率提升、风险防控、服务改进），这是文稿的"锚点"，不可缺失也不可空泛。
2. **话语忠实**：会议/文件精神引用必须准确到全称，不可编造；需要引用而用户未提供素材时，先询问再动笔；典故引用适度，每篇不超过 3 处。
3. **语言风格**：正式但不僵硬，带真情实感；避免空洞口号堆砌，每条感悟需有对应行动落脚；段落控制在 4-7 行；标题用"一、二、三"中式编号；结尾有升华和决心表态。
4. **长度控制**：学习心得体会 800-1200 字；思想汇报 1200-1800 字；组织生活会发言 1500-2000 字；研讨发言稿 600-1000 字；散文式征文 1000-1500 字。

### 质量自检清单

生成后逐项确认：

- [ ] 体裁结构完整（对照模板检查各部分是否齐全）
- [ ] 话语体系正确（引用的文件/会议精神名称准确，非编造）
- [ ] 岗位锚点到位（至少一处落到本人本职工作的具体行动）
- [ ] 三段式比例均衡（学习→感悟→行动，不头重脚轻）
- [ ] 无AI腔（避免"总之""综上所述""值得一提的是""需要指出的是"等套路词）
- [ ] 无行业/单位专属话语残留（通用模板不得出现任何特定单位、特定行业的专有名词）
