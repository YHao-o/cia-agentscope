## 1. 设计原理

写材料的参考需求有四类，对应的解决方式不同：

| 参考需求 | 解决方式 |
|---------|---------|
| "这个文种应该长什么样" | 查文种结构模板（本技能模板库、123456 框架） |
| "别人在同题材料里怎么谋篇布局" | **智能搜索参考（本文件）** |
| "这个会议/文件讲了什么、要求是什么" | 集上情（用户自己提供素材、官方来源回验） |
| "别人用哪些好词好句" | 话语体系库 + 五层借鉴法的语言层 |

本文件专管第二类。目标不是"找一篇文章来改"，而是**找到多个高质量样本，提炼可迁移的结构方法**。

**为什么要屏蔽本单位**：一是照抄本单位旧稿属于重复利用存量，领导一眼看穿；二是同题同单位极易撞车，失去新鲜感；三是本单位稿的视角受限于自身格局，天花板低。

**借鉴对象为什么平级优先**：同层级、业务相近的平级单位与用户有最重合的业务场景和受众层级，范文可迁移性最强，结构和做法可直接对标；上级主管部门代表官方口径，但主要用于**核对提法**而非直接对标文风；央企总部/省属龙头用于补谋篇布局的大格局表达。

## 2. 单位识别与体系推断

### 2.1 识别来源（按优先级）

1. 用户直接说明（"我们是水电八局""我在 XX 市水利局"）
2. 素材中出现的落款、抬头、会议名称
3. 用户历史偏好/画像中已记录的单位背景
4. 以上都没有 → **必须主动询问**，三问法：
   - 您所在单位的全称或简称是？
   - 写作主题与文体是？
   - 有无想重点参考的单位或明确要避开的单位？

### 2.2 推断行业与层级

识别出单位后，补全三个信息：

| 信息 | 用途 |
|------|------|
| 行业/领域 | 决定借鉴对象的选取范围 |
| 层级（中央/省/市/县/企业级） | 决定对标哪个层级的文风 |
| 单位性质（机关/事业单位/国企） | 决定话语体系和约束边界 |

简称须还原全称后再检索（如"水电八局"→"中国水利水电第八工程局"），否则屏蔽不全。

## 4. 检索策略与查询模板

### 4.1 检索入口（按可用性排序）

1. **通用搜索引擎 + Site 限定**：`关键词 site:mp.weixin.qq.com`（覆盖最全，优先）
2. **搜狗微信**：weixin.sogou.com（可按公众号筛选）
3. **微信"搜一搜"→"文章"**：需在用户自己的微信里执行（若无法使用，以前两种方式为主）
4. 目标公众号的"历史文章"或"服务号菜单"内检索（精准但慢）

### 4.2 查询公式

```
基础式：  主题词 + 文体/材料类型 + 借鉴单位(或行业词)
排除式：  上方结果后追加  -本单位简称 -本单位全称 -本单位主要下级
平台限定：site:mp.weixin.qq.com
```

### 4.3 按文体的查询模板（直接替换花括号）

| 文体 | 模板 |
|------|------|
| 工作部署讲话 | `{主题} 工作推进会 讲话 {借鉴单位} site:mp.weixin.qq.com` |
| 工作总结/汇报 | `{主题} 半年工作总结 经验做法 {行业词} site:mp.weixin.qq.com` |
| 党委(扩大)会报告 | `{年份} {主题} 党委工作报告 {借鉴单位} site:mp.weixin.qq.com` |
| 学习心得体会 | `学习 {会议/文件全称} 心得体会 {行业词} site:mp.weixin.qq.com` |
| 研讨发言 | `{主题} 研讨发言 {借鉴单位} 体会 site:mp.weixin.qq.com` |
| 典型经验交流 | `{主题} 典型经验 交流发言 {行业词} site:mp.weixin.qq.com` |

### 4.4 多轮检索策略

- 第 1 轮不理想 → 同义主题词扩展（"安全生产"→"质量安全管理"→"隐患排查整治"）
- 样本不足 → 扩大借鉴池（从同体系扩到同行业、从同行业扩到"浙江宣传"类通用借鉴库）
- 结果过老 → 加年份过滤（近 3 年优先，政策性表述以最新口径为准）

### 4.5 结果筛选标准

满足 **任意两条** 视为优质样本：
1. 发文主体是权威单位（主管部门/央企总部/省级以上）
2. 文章结构完整、板块比例清晰
3. 小标题有明确的"打法"而非大而化之
4. 有近 3 年的时效，口径不过时

## 5. 五层借鉴法

对每篇优质样本，只从五层抽取可迁移要素；其他内容一律不碰。

| 层级 | 学什么 | 记录要点 |
|------|--------|---------|
| 1. 结构层 | 全篇板块划分、顺序与比例 | 逐段标注板块功能（形势/部署/要求） |
| 2. 标题层 | 大标题立意 + 小标题打法 | 对应到七种标题方式（重复/比喻/拆分/递进/排比/并列/问题） |
| 3. 论证层 | 每个观点如何推进（问题→分析→对策；事实→启示→行动） | 记录论证链条，而非具体结论 |
| 4. 语言层 | 过渡句、段首句、金句的**句式结构** | 金句记录句式骨架，不使用原意象 |
| 5. 责任层 | 对方文章的发布场景、受众、立场 | 判断本文哪些对本任务不适用 |

**禁止学习**：具体事实与数据、对方单位的品牌提法、内部管理细节、原文整段表述。

**央媒口径回验**：样本中引用的中央表述、政策提法，回到官方原文核对（不排除对方写错或过时）。

## 6. 参考笔记模板

每次检索完成后，用固定模板沉淀结果，再并入"集素材"环节：

```markdown
【参考笔记】
任务：{写作主题 + 文体}
屏蔽清单：{本单位全称/简称/下级单位}
借鉴对象：{单位A}《{文章标题}》 {url} {发布日期}
结构拆解：{板块1 → 板块2 → 板块3，比例说明}
标题亮点：{小标题原文 + 所属标题方式}
论证亮点：{哪个段落用哪种推进方式}
可迁移点：
1. {对当前任务直接可用的结构/论证方法}
2. ...
不可迁移/需回验：
- {需要本行业替换的话语}
- {需要回验官方原文的政策表述}
对当前任务的启发：{1-2 句话，直接指导动笔}
```

参考笔记产出后，进入 123456 框架"第 3 步·集素材"，**作为素材的一部分**，最终仍按"领任务→列提纲→集素材→写正文"的正规流程成稿。

## 7. 完整示例（水利水电八局）

**任务设定**：用户单位 = 中国水利水电第八工程局有限公司（水电八局，属中国电建旗下），任务 = 起草《在公司 20XX 年半年工作推进会上的讲话》。

### 第一步：锁定屏蔽清单

- 中国水利水电第八工程局（含简称：水电八局、水电8局）
- 八局下属二级单位（各分局/专业公司公众号）

### 第二步：锁定借鉴对象

| 优先级 | 对象 | 理由 |
|-------|------|------|
| 1 平级标杆 | 中建三局、中交二航局、中铁四局 | 同层级工程局，业务同构，写法可直接对标 |
| 2 行业主管 | 长江水利（长江水利委员会）、中国水利 | 核对政策口径与行业提法 |
| 3 央企总部 | 中国电建、中国能建、中国建筑 | 谋篇布局与大格局表达 |
| 4 写法借鉴 | 长江航道、浙江宣传、人民日报评论 | 开头与标题的打磨样板 |

### 第三步：检索式示例

```
半年工作 推进会 讲话 中国电建 site:mp.weixin.qq.com -水电八局 -水利水电第八工程局
工程建设 百日攻坚 经验做法 中建 site:mp.weixin.qq.com
水利建设 高质量发展 部署 长江水利 site:mp.weixin.qq.com
```

### 第四步：参考笔记样例（节选）

```
借鉴对象：中国电建《XXX》
结构拆解：形势研判(1/5) → 上半年回顾(1/5) → 存在问题(1/5) → 下半年部署(2/5)
标题亮点：小标题采用"递进式"——'稳基本盘、补关键板、锻长板'
可迁移点：问题板块单独列出、不放在回顾里，使部署更有针对性
不可迁移：电建"水风光储一体化"提法 → 需替换为八局当前主业口径
```

## 8. 红线与常见错误

### 三条红线

1. **只做借鉴不做搬运**：严禁整段、整句照用范文原文；文章文责在发文单位，移花接木必有穿帮风险。
2. **检索词不含涉敏内容**：内部会议细节、未公开数据、人事安排等不作为检索词外发。
3. **含混引用必须回验**：样本中的中央表述、数据口径一律回到官方原文核对。

### 常见错误清单

1. 把"找范文"做成"找一篇范文改一改"——正确做法是多样本、五层抽取。
2. 屏蔽只做简称不做全称——漏掉"水利水电第八工程局"变体，照样撞车。
3. 把对方当年的数据当作自己的依据——数据必须来自本单位真实素材。
4. 参照了样本但忘了回验政策口径——样本会过时，政策不会为你暂停。
5. 借鉴对象选"和本单位最像的小单位"——天花板低；应向上一级标杆看齐。
