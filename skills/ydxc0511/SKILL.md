# 体制内公文写作与讲话稿起草（123456 框架）

> **使用方式**：先查下面的加载表，只读当前需要的那一份；读完一份再读下一份，不要一次性把参考文件全读完。

## 概述


本技能基于十六年"笔杆子"实操经验，将体制内公文写作与领导讲话稿起草的方法论提炼为"123456"逻辑框架——**一大本质、两个标准、三类原则、四项功夫、五种心态、六个步骤**。覆盖从领受任务到最终定稿的全流程，适用于党政机关、企事业单位的文字工作者。

四类任务入口：
1. **领导讲话稿与事务公文**——按"核心工作流"六步执行；
2. **录音/散素材整理成公文**——按"录音与素材自动整理工作流"执行；
3. **一般工作人员个人发言类**（心得、汇报、对照检查、研讨、征文）——按"小型会议发言工作流"执行；
4. **找同行范文参考**——按"智能搜索参考工作流"执行。

增殖机制：检索类借鉴（屏蔽本单位借鉴同行）与复盘沉淀（成稿后被追问即沉淀一条学习，每次≤1句、总量≤10句）能让技能越用越贴合用户偏好。

## 快速上手（真实对话示例）


- "帮我写一篇支部书记在七一表彰大会上的讲话，讲稿内需含党建和业务融合内容" → 核心工作流（讲话稿）
- "把这段录音整理成会议纪要，发言人说了三点" → 录音与素材自动整理工作流
- "电厂安监专责，开党员民主生活会要说两句，帮我写个对照检查的个人发言" → 小型会议发言工作流（对照检查体裁）
- "我们是水电八局，参考一下同行单位是怎么写半年工作总结的吧" → 智能搜索参考工作流（屏蔽本单位，借鉴同行）
- "这是我去年写的心得体会，帮我对照新一年的工作要求改改" → 范文对照 + 核心工作流定稿
- "帮我写篇情感故事" "给新产品写个营销软文" → 反例（不属本技能范围，明确说明）

**万能启动方式**：只需一句话描述需求（文体+场合+大概内容）即可，本技能会自动追问必补信息（背景、受众、数据等），无需预先整理完整材料。

完整成品示例（研讨发言全文）见 `references/essays/通用研讨发言.md`，用户要看成品时再读。

## 快速参考：123456 框架


| 编号 | 维度 | 核心要点 |
|------|------|----------|
| 1 | 一大本质 | **以文辅政**——公文是公共政策的"文字化"，核心价值在于研究解决问题 |
| 2 | 两个标准 | **领导点头**（谋到位、想到位、跟到位）+ **阅者点赞**（有思想性、有针对性、有新鲜感） |
| 3 | 三类原则 | **立意有高度**（上级精神+全局角度+先进经验）+ **内容有深度**（量身定制、不可复用）+ **表述有温度**（接地气、朴实鲜活） |
| 4 | 四项功夫 | **积累**（体例/素材/经验）+ **实战**（力戒眼高手低、粗暴粘贴、追求一般、低效重复）+ **学习**（争当行家/专家/杂家）+ **复盘**（复过程/复经验/复教训，善用花脸稿） |
| 5 | 五种心态 | **兴趣之心** + **责任之心** + **细致之心** + **耐熬之心** + **吃苦之心** |
| 6 | 六个步骤 | **领任务**（精准不偏差）→ **列提纲**（纲举而目张）→ **集素材**（全面不遗漏）→ **写正文**（统分相结合）→ **善润色**（意新且词亮）→ **呈定稿**（三审而后定） |
